Move JSON Schema

Home Game JSON Raw JSON-Schema

Overview

The Move payload represents a player turn: either a direction or an item use.

Example – direction

{ "direction": "Right" }

Example – item

{ "item_name": "Bomb" }

Interactive schema

Definitions

Direction
"Up" | "Down" | "Left" | "Right"
item_name
String identifier for an item, e.g. "Bomb"
