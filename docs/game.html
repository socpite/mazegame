Overview

The Game payload includes the maze board, player position, end position, and item list.

Example

{
  "board": {
    "height": 3,
    "width": 3,
    "vertical_walls": [
      ["BorderWall","NoWall","NoWall","BorderWall"],
      ["BorderWall","NoWall","NoWall","BorderWall"],
      ["BorderWall","NoWall","NoWall","BorderWall"]
    ],
    "horizontal_walls": [
      ["BorderWall","BorderWall","BorderWall"],
      ["NoWall","NoWall","NoWall"],
      ["BorderWall","BorderWall","BorderWall"],
      ["BorderWall","BorderWall","BorderWall"]
    ],
    "luminated_tiles": [
      [true,false,false],
      [true,true,false],
      [false,false,false]
    ],
    "buffer_board": [
      [0,0,0],
      [0,0,0],
      [0,0,0]
    ],
    "item_board": [
      [null,"Bomb;{\"timer\":3}",null],
      [null,null,null],
      [null,null,null]
    ]
  },
  "position": [0,0],
  "end_position": [2,2],
  "item_list": ["Bomb;{\"timer\":3}"]
}

Fields

  • board: full MazeBoard object
  • position: starting tile ([row, col])
  • end_position: goal tile ([row, col])
  • item_list: array of serialized items
